# III Torneo Nacional de Debate · NNGG España

Aplicación web móvil/PWA del III Torneo Nacional de Debate de NNGG España.

- Formato: debate académico.
- 13 sedes clasificatorias.
- Vitoria-Gasteiz: 10 de octubre de 2026.
- Gran final: Madrid, 24 de octubre de 2026.
- Tema de la gran final: se anunciará el 11 de octubre.

## Publicación
GitHub Pages debe configurarse en **Settings → Pages → Source: GitHub Actions**.
El workflow `.github/workflows/deploy.yml` compila con Vite y publica `dist`.
